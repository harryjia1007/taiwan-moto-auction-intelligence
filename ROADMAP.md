# Roadmap

The roadmap prioritizes trust and repeatability over the number of sources displayed.

## 0.1 — Public contributor baseline

- [x] Reproducible local fixture dashboard
- [x] Unit tests for shared normalization and five source adapters
- [x] CI for application, ingestion, and database layers
- [x] Public license, governance, security, and contribution policies
- [ ] Publish the first tagged pre-release
- [ ] Triage initial external feedback into labeled issues

## 0.2 — Verified live pipeline

- [ ] Complete a database-backed live sync for each implemented source
- [ ] Display sync freshness, partial failures, and artifact checksums in the UI
- [ ] Add source-contract monitoring for public page changes
- [x] Document data-retention and redaction operations
- [ ] Add end-to-end evidence-link tests

## 0.3 — Reusable civic-data components

- [ ] Extract a documented adapter contract for other public auction categories
- [ ] Add a fixture-authoring and sanitization guide
- [ ] Export evidence-linked data in a stable, machine-readable format
- [ ] Publish a source-health summary that can be consumed independently of the UI
- [x] Build a synthetic, privacy-separated public portfolio Demo and handoff package

## Later, subject to access constraints

- Administrative Enforcement Agency branches
- Prosecutors' office public notices
- Customs and direct police/traffic sources
- Explicitly authorized, human-confirmed paid vehicle-registry enrichment

Items remain planning records until their success criteria are met. The project will not bypass access controls or mislabel planned coverage as active.
