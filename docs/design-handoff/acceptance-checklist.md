# Design acceptance checklist

## Find and compare

- [x] Active, ended, and favorites are one tap/click away.
- [x] Search is visible in the first mobile viewport at 390 × 844.
- [x] Advanced mobile filters are collapsed until requested or already active.
- [x] Filter and sort state is representable in the URL.
- [x] A card exposes eligibility, registration, price type, deadline and bulk-lot state before secondary facts.
- [x] Missing photos have an intentional official-no-photo state, not a broken image.

## Decide and verify

- [ ] Detail begins with the 30-second decision brief and missing facts.
- [x] Price labels distinguish reserve, current and sold prices.
- [x] Date-only court events do not display an invented hour.
- [ ] Every consequential normalized fact can lead to exact official text.
- [x] The official notice/PDF action is prominent and vehicle-specific.
- [x] `UNKNOWN`, `NO`, and `CONFLICTING` have different text.

## Responsive and inclusive

- [ ] Desktop is reviewed at 1440 × 1000 and 1180 × 800.
- [ ] Mobile is reviewed at 390 × 844 and 360 × 800. (390 × 844 verified in this slice.)
- [x] No fixed action obscures content or browser safe areas.
- [x] Keyboard focus is visible; controls have accessible names.
- [ ] Text and status colors meet WCAG AA; color is never the only state cue.
- [x] Reduced-motion preference is respected.

## Trust

- [x] Passed deadlines are not labeled sold without an official result.
- [x] Planned source coverage is never presented as active.
- [x] Completeness is described as field coverage, not confidence.
- [x] No fake vehicle, price, photo, mileage or auction result is introduced.
