# 政府電子採購網財物變賣

官方開放資料：[資料集 7263「財物變賣公告」](https://data.gov.tw/dataset/7263)

官方 XML：<https://web.pcc.gov.tw/opas/aspam/public/downloadOpenData>

## 目前政策：ALLOW（官方機器資料源）

這個決策不是從模糊的 `robots.txt` 回應推定而來。行政院公共工程委員會已把「財物變賣公告」明確發布為機器可讀 XML：免費、採政府資料開放授權條款第 1 版（OGDL 1.0），更新頻率為每一上班日，涵蓋近一週公告。

自動 discovery 僅下載一次官方 XML，不再對一般查詢頁逐字輪詢。XML 只含機關名稱、標案案號、公告次數、財物名稱與公告日期，因此 adapter 只用這五個官方欄位建立身分並篩選名稱含「汽車」、「機車」或「車輛」的公告；鐵路／電力／柴油／蒸汽機車會排除，避免把鐵路車輛當成道路車輛。

## 明細與完整性

XML 沒有公告主鍵或明細網址。對每個命中的項目，adapter 才用機關名稱加標案案號查詢同一官方網站，並逐一比對機關、案號、公告次數、財物名稱與公告日期。必須恰好命中一筆才讀取 `https://web.pcc.gov.tw` 的公開明細；零筆或多筆都 fail closed，不猜測、不串錯案件。

明細解析機關、案號、公告次數、公告／截止日期、底價、保證金、資格、標的所在地、查看時間與附加說明。重要欄位保存逐字官方證據。投標資格含廢機動車輛回收資格時標為 `LICENSED_RECYCLER_ONLY`。

處分性質依公告文字判定，不依刊登機關猜測：

- 交通違規移置、逾期未領回：`IMPOUNDED_UNCLAIMED`
- 扣押、沒收、沒入：`CRIMINAL_SEIZURE_OR_FORFEITURE`
- 明確報廢／廢機車：`SCRAP_DISPOSAL`
- 其餘公有財物變賣：`PUBLIC_ASSET_DISPOSAL`

若頁面沒有分列車牌、引擎或車身號碼，不建立虛構車輛；保留為可搜尋的整批 lot。只寫「報廢財產一批」而 XML 財物名稱未提汽車、機車或車輛者不會被猜成車輛。外部機關附件網址只保留為證據，必須先把該官方網域登錄到專屬來源後才會下載。

排程可每日執行兩次，但官方 XML 僅在上班日每日更新；重複同步會保留快照且不製造重複案件。來源只有在一次正式同步完全成功後才會由 `PARTIAL` 升為 `ACTIVE`。
