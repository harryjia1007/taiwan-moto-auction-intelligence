# 司法院 22 地院動產法拍

## 目前政策：查詢站禁止自動 discovery，官方 PDF 清單可人工匯入

截至 2026-08-15，中央法拍查詢站的官方 `robots.txt` 對所有路徑標示 `Disallow: /`，所以不得以該查詢表單執行無人 discovery。這不代表司法院公告內容一概不能再利用：司法院網站資料開放宣告原則上採「政府資料開放授權條款第 1 版」，允許標示出處後重製、改作與公開傳輸，並明示一般連結無須事前同意；個資、第三方圖像、商標與特別聲明排除項目仍須分開處理。

司法院曾提供「法拍屋動產及不動產待拍資料集」（資料集 49107），但政府資料開放平台於 2023-01-12 公告永久下架；舊資源 `Foreclosure.json` 目前亦無法連線。因此目前不是因為內容不能公開，而是沒有仍有效、允許機器介接的官方替代 feed。來源政策為 `MANUAL_ONLY`：人工從官方查詢結果取得 PDF 網址並核對法院、案號、日期、拍次與標的名稱後，可匯入 JSON manifest；匯入程式只保存結構化欄位與官方 URL，不會查詢中央表單或下載／鏡像 PDF。官方恢復資料集、提供 API／匯出檔或書面確認可用介接方式後，才重新啟用 unattended discovery。

執行方式：

```bash
python -m ingest sync --source judicial --manifest ./private/judicial-official-links.json
```

Manifest 每列必須使用 `https://aomp109.judicial.gov.tw/judbp/wkw/WHD1A02/DO_VIEWPDF.htm?filenm=...pdf`，並包含 `crtnm`、`crm`、`saledate`、`saleno`、`ttitle` 等人工核對過的官方欄位。正式 manifest 含真實案件資料，不得提交到公開 Git repository。

人工清單亦可保存從同一份官方公告逐字核對的 `sale_time`、`location` 與車輛備註。解析器會保留拍賣時間（不只日期）、所在地、里程及鑰匙／發動／測試的四態語意；例如「無法測試」仍不會被推成「無法發動」。公開投影不包含債權人、債務人、引擎號碼或 PDF 全文。

截至 2026-08-15，公開 feed 已人工核對並加入 4 件拍賣日在未來的官方公告（8 月 19 日、8 月 21 日、8 月 27 日及 9 月 8 日）。第三方整理站只用於發現可能漏件；案件欄位、狀態與連結均回到司法院官方 PDF 核對。這 4 件不能解讀為全國自動 discovery 已恢復，來源仍維持 `MANUAL_ONLY`。

## 公開呈現方式

- 本站可整理官方允許再利用的結構化案件欄位，清楚標示「資料來源：司法院／發布法院」。
- 「查看官方完整公告」永遠連到發布機關的原始頁面或 PDF，不把本站 Storage 簽名網址當成官方全文。
- 私有 checksum／稽核副本只用於解析追溯與來源更正，不公開鏡像。
- 官方來源若含姓名、完整車身／引擎號碼或其他非必要個資，公開版採資料最小化；車牌是否完整顯示依個案必要性與法務複核決定。
- 官方頁或附件若另有第三方權利／禁止再利用聲明，該素材不進公開版。

## 既有解析能力

Adapter 使用司法院「法拍屋公告查詢系統」的中央動產查詢，法院欄位選擇「全部」、財產種類選擇「動產」，以機車關鍵字發現全國 22 個地方法院的公開案件。這是司法強制執行法拍，與法院透過政府電子採購網出售自己的報廢公務車完全不同。

## 歷史取用流程（目前不得執行 live discovery）

1. 讀取官方 V1/V2 表單並取得 CSRF/token。
2. 以 `proptype=C54`、`saletype=1` 與機車關鍵字查詢。
3. 以官方 `rowid` 去重，每筆保存結構化結果 JSON。
4. 另下載並私密保存官方拍賣公告 PDF。
5. 以結構化欄位建立欄位級證據；PDF 原文保留供查核與未來版本再解析。

舊流程的網域、頻率、重試與 MIME 保護仍保留在程式中，但來源政策 preflight 會阻擋沒有 manifest 的 live sync。`python -m ingest reprocess --source judicial` 只讀私有保存內容，不連官方網站。不得以第三方法拍整理站作為替代爬取來源；第三方頁面只能用來研究產品呈現，案件資料仍須回到官方來源。

## 保守語意

- 查詢結果的 `sumprice=0` 視為未揭露，不顯示為零元底價。
- 官方只給日期時，前台只顯示日期，不虛構拍賣時間。
- 未在結構化結果明示的投標資格、牌照狀態、車況與點交方式維持 `UNKNOWN`。
- 頁面消失不會自動推論為 `SOLD`。
