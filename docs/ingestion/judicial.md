# 司法院 22 地院動產法拍

## 目前政策：查詢站禁止自動 discovery，官方 PDF 清單可人工匯入

截至 2026-08-23，中央法拍查詢站的官方 `robots.txt` 仍對所有路徑標示 `Disallow: /`，所以不得以該查詢表單執行無人 discovery。這不代表司法院公告內容一概不能再利用：司法院網站資料開放宣告原則上採「政府資料開放授權條款第 1 版」，允許標示出處後重製、改作與公開傳輸，並明示一般連結無須事前同意；個資、第三方圖像、商標與特別聲明排除項目仍須分開處理。

司法院曾提供「法拍屋動產及不動產待拍資料集」（資料集 49107），但政府資料開放平台於 2023-01-12 公告永久下架；舊資源 `Foreclosure.json` 目前亦無法連線。因此目前不是因為內容不能公開，而是沒有仍有效、允許機器介接的官方替代 feed。來源政策為 `MANUAL_ONLY`：人工從官方查詢結果取得 PDF 網址並核對法院、案號、日期、拍次與標的名稱後，可匯入 JSON manifest；匯入程式只驗證並保存 manifest 內的結構化欄位與官方 URL，不會查詢中央表單、開啟 PDF URL、下載／鏡像 PDF，亦不會建立 HTTP session。未提供 manifest 時，discovery 在任何網路請求前直接拒絕執行；healthcheck 也只回報人工模式，不探測 aomp109。官方恢復資料集、提供 API／匯出檔或書面確認可用介接方式後，才重新啟用 unattended discovery。

執行方式：

```bash
python -m ingest sync --source judicial --manifest ./private/judicial-official-links.json
```

Manifest 每列必須使用 `https://aomp109.judicial.gov.tw/judbp/wkw/WHD1A02/DO_VIEWPDF.htm?filenm=...pdf`，並包含 `crtnm`、`crm`、`saledate`、`ttitle` 等人工核對過的官方欄位。只有官方公告明確寫出拍次時才填 `saleno`；否則填 `UNKNOWN`，不得從第三方網站推定。正式 manifest 含真實案件資料，不得提交到公開 Git repository。

匯入後的 JSON artifact 會標成 `human-reviewed-manifest-row`，明確表示它不是官方 API 回應、官方 query result 或 PDF 原文。逐字輸入的欄位證據信任為 `UNKNOWN`，解析器從該列計算的欄位為 `SYSTEM_CALCULATED`；官方 PDF 外連仍保留供人工覆核。若拍賣日期缺漏，狀態為「已公告／日期未知」，不得自動標成「預定拍賣」。

公開層目前只採用已人工核對的司法院官方公告。第三方整理站可作為「可能漏件」的覆蓋率訊號，但不得直接成為本站案件來源，也不得作為成交、成交價、拍次或車況的證據。每個候選都必須回到官方 PDF，核對法院、案號、日期、拍次與標的文字後才可匯入。官方文件沒有成交結果時，只標示「已截止／結果待官方確認」。完整 PDF 由使用者直接開啟司法院原站，本站不建立公開鏡像。

人工清單亦可保存從同一份官方公告逐字核對的 `sale_time`、`location` 與車輛備註。解析器會保留拍賣時間（不只日期）、所在地、里程及鑰匙／發動／測試的四態語意；例如「無法測試」仍不會被推成「無法發動」。公開投影不包含債權人、債務人、引擎號碼或 PDF 全文。

第三方頁面宣稱可以每日或每週整理 aomp109，也不構成本站取得相同存取授權的證據；免責文字亦不能取代來源政策。若未來取得正式 API、開放資料、授權匯出檔或書面許可，才可將 `judicial` 從 `MANUAL_ONLY` 改為 `ALLOW`。在此之前，來源頁會明示「人工核對／非全國自動覆蓋」，避免把資料筆數誤解為完整母體。

## 公開呈現方式

- 本站可整理官方允許再利用的結構化案件欄位，清楚標示「資料來源：司法院／發布法院」。
- 「查看官方完整公告」永遠連到發布機關的原始頁面或 PDF，不把本站 Storage 簽名網址當成官方全文。
- 私有 checksum／稽核副本只用於解析追溯與來源更正，不公開鏡像。
- 官方來源若含姓名、私人地址、完整車身／引擎號碼或其他非必要個資，公開版採資料最小化；車牌一律依公開投影規則部分遮蔽，日期未知不顯示，確認截止 30 天後移除，不公開完整車牌。
- 官方頁或附件若另有第三方權利／禁止再利用聲明，該素材不進公開版。

## 已移除的歷史取用流程（稽核紀錄，不是操作指示）

早期版本曾執行下列步驟；現行 adapter 已移除這些網路能力，不能以本節重建 live discovery：

1. 讀取官方 V1/V2 表單並取得 CSRF/token。
2. 以 `proptype=C54`、`saletype=1` 與機車關鍵字查詢。
3. 以官方 `rowid` 去重，每筆保存結構化結果 JSON。
4. 另下載並私密保存官方拍賣公告 PDF。
5. 以結構化欄位建立欄位級證據；PDF 原文保留供查核與未來版本再解析。

現行程式不再提供中央查詢 discovery。`python -m ingest reprocess --source judicial` 只讀私有保存內容，不連官方網站；正式新增資料只能使用人工核對 manifest。不得以第三方法拍整理站作為替代爬取來源；第三方頁面只能用來做覆蓋率差距與產品呈現研究，案件資料仍須回到官方來源。

## 保守語意

- 查詢結果的 `sumprice=0` 視為未揭露，不顯示為零元底價。
- 官方只給日期時，前台只顯示日期，不虛構拍賣時間。
- 未在結構化結果明示的投標資格、牌照狀態、車況與點交方式維持 `UNKNOWN`。
- 頁面消失不會自動推論為 `SOLD`。
