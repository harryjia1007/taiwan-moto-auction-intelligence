# 司法院 22 地院動產法拍

## 涵蓋範圍

Adapter 使用司法院「法拍屋公告查詢系統」的中央動產查詢，法院欄位選擇「全部」、財產種類選擇「動產」，以機車關鍵字發現全國 22 個地方法院的公開案件。這是司法強制執行法拍，與法院透過政府電子採購網出售自己的報廢公務車完全不同。

## 取用流程

1. 讀取官方 V1/V2 表單並取得 CSRF/token。
2. 以 `proptype=C54`、`saletype=1` 與機車關鍵字查詢。
3. 以官方 `rowid` 去重，每筆保存結構化結果 JSON。
4. 另下載並私密保存官方拍賣公告 PDF。
5. 以結構化欄位建立欄位級證據；PDF 原文保留供查核與未來版本再解析。

所有請求限 `aomp109.judicial.gov.tw`，每秒最多一次、三次有界重試、25 MiB 上限，並驗證 HTML／JSON／PDF MIME 與 PDF magic bytes。無登入、無 CAPTCHA、自動投標或反自動化繞過。

## 保守語意

- 查詢結果的 `sumprice=0` 視為未揭露，不顯示為零元底價。
- 官方只給日期時，前台只顯示日期，不虛構拍賣時間。
- 未在結構化結果明示的投標資格、牌照狀態、車況與點交方式維持 `UNKNOWN`。
- 頁面消失不會自動推論為 `SOLD`。
