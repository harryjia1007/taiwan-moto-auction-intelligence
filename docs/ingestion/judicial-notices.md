# 司法院主站「其他司法公告」車輛拍賣補充來源

## 定位

`judicial_notices` 是獨立的補充來源，只讀司法院全球資訊網的[其他司法公告](https://www.judicial.gov.tw/tw/lp-1913-1.html)。它不是 `aomp109` 動產拍賣公告系統的替代 API，也不能代表全國 22 所地方法院的動產拍賣已完整收錄。來源在完成健康的正式同步前維持 `PARTIAL`；零筆結果只代表這個補充公告面在指定期間與關鍵詞下沒有符合項目。

此 adapter 絕不連線至 `aomp109.judicial.gov.tw`。原本的 `judicial` 來源仍依其 `MANUAL_ONLY` 政策處理人工審核的官方清單，兩個來源不得混用健康狀態或涵蓋率。

## 存取邊界

- 唯一網域：`www.judicial.gov.tw`，HTTPS 443。
- 可請求路徑：`/robots.txt`、`/tw/lp-1913-...html`、`/tw/cp-1913-...html`。
- 每次 discovery 先重新讀取 robots；缺少 `User-agent`、相關路徑遭禁止、robots 重新導向、403 或 429 均立即 fail closed。
- 2026-08-23 複查時，robots 沒有禁止 `/tw/lp-1913` 與 `/tw/cp-1913`；這只是目前的路徑政策快照，每次執行仍以即時 robots 為準。
- 固定可聯絡 User-Agent；全域每秒最多一個請求、最多三次有界重試、五次同網域重新導向、HTML 8 MiB、robots 256 KiB。
- 只接受官方 HTML 與 robots 純文字 MIME；未知版面、沒有官方零結果標記的空表、跨網域或跨路徑連結都停止或標記部分涵蓋。

## 搜尋與篩選

adapter 使用持久 HTTP session，先驗證官方 POST form，再提交網站現有欄位：

- `Action=Qeury`
- `Q_DMDeptMainID`
- `TBOXDMPostDateS` / `TBOXDMPostDateE`
- `Q_DMBody`
- `lstoken`
- `BtnSubmit`

張貼日嚴格限制在最近 180 天，日期使用民國年格式。搜尋詞涵蓋機車、普通／大型重型、汽車、車輛、小客車、小貨車、貨車、轎車、休旅車與廂型車。每個關鍵詞最多三頁，合計最多驗證 120 個詳細頁；達到任一上限必須留下 `PARTIAL` warning，不得聲稱完成全量搜尋。

全文搜尋可能回傳只在內文提到車輛的非拍賣公告。因此每一筆候選詳細頁必須同時包含明確車種語意與 `拍賣／標售／變賣／應買` 語意才會進入資料庫；「汽車燃料費」及「汽機車停車位」不會單獨成為車輛證據。

車輛詞也可能只出現在公司名稱或債權人名稱。`汽車股份有限公司`、一般燃料費、停車位或房地產公告不構成標的物證據；泛稱「汽車／車輛」必須和拍賣標的、車號、排氣量、引擎／車身識別或其他車輛資產脈絡相連。無法排除非車輛語境時直接略過，不為了提高筆數建立誤判案件。

## Artifact、附件與證據

- 保存每一筆命中的搜尋結果 HTML discovery artifact，以及該筆 `cp-1913` 詳細頁 HTML。
- 詳細頁是 primary artifact；所有 consequential normalized fields 都帶該詳細頁的確切 SHA-256 與官方原文。
- 只抽取同網域、無 query/fragment、符合 `/tw/dl-...html` 的官方附件網址為 `official_attachment_url` evidence。
- 不請求、不鏡像附件內容，不讀取或快取任何圖片，`photo_urls` 永遠是空陣列。
- `不得試車` 只形成 `can_test=NO`，不得推導 `can_start=NO`。沒有明文的發動、領牌、過戶、資格、價格或車況均維持 `UNKNOWN`。
- 已過拍賣時間只能標為 `EXPIRED`；頁面消失或時間已過不是 `SOLD` 證據。

## 可抽取欄位與限制

有明文時可抽取發布機關、案號、拍賣輪次與時間、底價、保證金、地點、車種／法定級別、廠牌、型號、排氣量、出廠年月、顏色、里程、車牌／引擎／車身識別、資格、領牌狀態、鑰匙、發動、試車、車況、費用與官方附件連結。來源不下載附件，因此只存在附件內、未出現在 HTML 的車輛不會被發現，這項缺口必須在 `/sources` 保持可見。

上述完整識別與逐字證據只保留在 owner 私人層。匿名投影不含引擎／車身識別，車牌只在規定期間部分遮蔽，並會隱去義務人、債務人、車主等角色的戶籍、通訊、聯絡、送達或居住地址；官方看車、保管、拍賣或領車地點在未被標示為私人地址時仍可保留。

司法院[資料開放宣告](https://www.judicial.gov.tw/tw/cp-1327-84674-d8e05-1.html)與 robots 存取許可是兩個不同判斷；可讀取 HTML 不代表可重製第三方照片、可忽略個人資料責任，或可把此補充頁宣稱為完整法拍資料庫。
