# 公路監理資料有償查詢補強

公路監理資料有償利用服務網是「人工授權的付費補強來源」，不是背景爬蟲來源。即時查詢目前標示每筆新臺幣 2 元，且查無資料通常仍會計費；登入、付款與每一筆查詢都必須由擁有者明確授權。

官方入口：<https://mvdvan.mvdis.gov.tw/mvdvan/>

## 能做與不能做

- 機車可用最新車牌、引擎號碼、車身號碼等官方允許的條件查詢，實際回傳欄位以查詢當下頁面為準。
- 車牌查詢可用來補強車籍基本資料與牌照狀態；涉及車主識別資料的進一步查詢不可由拍賣公告的公開資料取代。
- 官方表單將「最近里程、前次里程及其檢驗日期」標為機車不提供的欄位，因此不得把有償查詢描述成機車里程來源。
- 一般車牌英文字母不是出廠月份碼。`E` 字首可辨識電動機車牌別，但不能推算出廠月。出廠年月只接受官方公告、鑑價文件或監理查詢的明示資料。

## 安全流程

1. 使用者在本機瀏覽器自行登入 HiNet／監理服務，不把密碼貼入程式碼、對話或資料庫。
2. 系統在扣款前顯示車牌、預估筆數與總金額，由使用者逐批確認。
3. 使用者將合法取得的查詢結果匯入；保存查詢時間、使用的識別條件、回傳欄位及可稽核的官方證據。
4. 每個補強欄位新增 observation 與 field evidence，不覆寫或刪除既有拍賣公告證據；衝突時依信任層級並列顯示。

此 production slice 只提供官方入口與資料模型準備，不自動化登入、扣款、CAPTCHA 或任何規避存取限制的行為。
