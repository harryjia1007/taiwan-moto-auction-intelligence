# 海關四關車輛標售

本切片只讀取財政部關務署官方網域 `https://web.customs.gov.tw` 的伺服器回傳 HTML，不提交搜尋表單、不處理驗證碼，也不下載 `/download/` 下的附件。附件網址與官方顯示名稱會保留為證據連結，讓使用者回到官方頁面查看；附件檔案不會進入本專案的 Storage。

## 涵蓋入口

- 四關總覽：`/singlehtml/1207?cntId=cus1_93228_1207`
- 基隆關：`/keelung/multiplehtml/572`
- 臺北關：`/taipei/multiplehtml/120`
- 臺中關：`/taichung/multiplehtml/396`
- 高雄關：`/kaohsiung/multiplehtml/541`

每一關最多讀取五個清單頁，每頁最多檢查二十則同頻道公告，請求間隔至少一秒。所有重新導向都會在送出下一個請求前重新驗證；只允許 HTTPS、標準連接埠與 `web.customs.gov.tw`。`403`、`429`、非 HTML、超過 5 MiB、網域或路徑不符時均停止或記錄失敗，不會改用瀏覽器規避限制。

## 收錄規則

公告標題或 HTML 本文必須明確出現汽車、機車、重機、小客車、貨車、公務車，或「標售／拍賣／報廢車輛」等可重現文字，才會建立資料。只有一般「通信標售」名稱、或車種只存在附件清表中的公告，不會被推定成汽機車。

可由 HTML 證明時，解析關別、發文字號、開標時間與地點、車種、法定機車級別、汽車分類、車牌、廠牌、型號、排氣量、數量、資格及領牌限制。未明示的欄位保留 `UNKNOWN`；過期日期只代表公告已結束，不代表成交。

## 已知限制與上線條件

海關多數定期標售把逐項品名、底價、押標金與照片放在 `/download/` 附件。現行 robots 政策不允許本收集器取得該路徑，因此 HTML 切片無法宣稱完整涵蓋附件內車輛。來源健康狀態固定以 `PARTIAL` 呈現，直到取得可重用的官方資料集、書面許可，或官方另提供不受限制的結構化清單。

在來源清冊與資料庫 policy 改為 `ALLOW`、完成一次無失敗 live sync 前，adapter 程式存在不等於正式上線。主流程整合時仍須加入 `source_policy.py`、CLI、seed 與排程；本檔不授權擴大到其他財政部或第三方網域。

## 測試

`services/ingest/tests/test_customs_adapter.py` 使用合成且已去識別 fixture，驗證有限分頁、同頻道 URL、HTML 車輛辨識、附件只留連結、網域與 `/download/` 阻擋、非 HTML fail-closed。測試不連線到官方網站。
