# Ingestion Architecture

Adapters implement independent asynchronous discovery, fetch, parse, and healthcheck stages. A failed item is recorded without rolling back successful items, while a failed source never changes prior auction statuses.

Run health and access authorization are separate. Only an `ALLOW` source with a fully successful run can become `ACTIVE`; a mixed successful/failed run stays `PARTIAL`, and a failed run becomes `DEGRADED`. A clean human-assisted `MANUAL_ONLY` import may advance `last_successful_at`, but its source remains `PARTIAL`; `REVIEW_REQUIRED` remains `DEGRADED` and `DISABLED` remains `DISABLED` regardless of run outcome. Thus a valid manual import records freshness without misrepresenting automated coverage.

A source may safely parse a lower-completeness record after a deeper detail request is blocked. Such an item increments both `parsed` (the retained official summary) and `failed` (the unavailable detail stage), adds an explicit warning, and keeps the run `PARTIAL`. This deliberately distinguishes “the official central list proves the auction exists” from “all detail evidence was collected.”

Network safeguards include an HTTPS host allowlist, one-request-per-second pacing, two retries with bounded backoff, 20-second timeouts, a 25 MiB artifact limit, checksum-addressed writes, and MIME validation. Downloads are treated as bytes; scripts and macros are never executed. Storage writes are idempotent only when Supabase returns its exact duplicate-object signature (`409` / `Duplicate` / `KeyAlreadyExists`); authorization, bucket, and all other upload failures remain run failures.

`python -m ingest sync --source <key>` runs each implemented source in isolation. Hosted `ALLOW` sources are `moj_auction`, `pcc`, `customs`, and `moj_enforcement_cms`; `shwoo` remains an approved Taiwan-network batch source because GitHub-hosted full discovery repeatedly timed out. Every public publisher preserves private artifacts and snapshots before updating the sanitized projection. PCC reads official dataset 7263 XML once per run and resolves only an exact five-field same-host match. Customs reads the four official HTML channels but never fetches `/download/` attachments. Administrative Enforcement branch discovery preflights each of 13 explicitly registered CMS hosts, while the separate `moj_enforcement` adapter accepts only a human-exported central-search manifest and never submits or solves the CAPTCHA. `healthcheck` is bounded and reprocessing consumes stored artifacts without live discovery.

Discovery warnings are first-class run state. If one branch or list fails, the run is `PARTIAL` even when other cases were parsed. If discovery itself raises before any record can be parsed, the run is `FAILED`. Neither condition deletes prior records or advances a misleading successful timestamp.

The marketplace read model unions identified vehicles with inseparable official lots. A bulk notice without separable identities remains a lot and may be displayed, but it cannot be favorited as a made-up vehicle.
